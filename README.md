# 🐾 AmitVet — מערכת לניהול מרפאה וטרינרית

אתר לניהול משימות ותקשורת בין לקוחות לווטרינר הראשי. לקוחות רשומים יכולים
לשלוח פניות, לקבוע פגישות ולנהל את החיות שלהם; הווטרינר מנהל הכל מלוח בקרה אחד.

הממשק כולו בעברית עם תמיכה מלאה ב-RTL.

## יכולות

**ללקוח:**
- הרשמה והתחברות
- ניהול חיות מחמד (סוג, גזע, מין, גיל, משקל, הערות)
- צפייה בהיסטוריה רפואית ובחיסונים של החיה
- בקשת תורים (בדיקה, חיסון, ניתוח, חירום ועוד) וביטולם
- פתיחת פניות לווטרינר וצ'אט דו-כיווני בשרשור

**לווטרינר הראשי:**
- לוח בקרה: בקשות פגישה ממתינות, פניות פתוחות, תורי היום, חיסונים מתקרבים
- אישור / דחייה / קביעה-מחדש של פגישות והוספת הערות
- מענה לפניות וניהול סטטוס (פתוח / בטיפול / נסגר) ודחיפות
- ניהול רשומות רפואיות וחיסונים לכל חיה
- רשימת כל הלקוחות והמטופלים

## הפעלה

```bash
npm install
npm start
```

ואז גלשו אל http://localhost:3000

## מבנה טכני

- **שרת:** Node.js + Express
- **מסד נתונים:** SQLite מובנה (`node:sqlite`) — ללא תלות חיצונית. הקובץ נשמר ב-`data/amitvet.db`
- **אימות:** JWT בעוגייה מסוג httpOnly, סיסמאות מוצפנות ב-bcrypt
- **ממשק:** HTML/CSS/JS טהור (ללא שלב build), RTL

```
server/
  index.js          הגדרת Express ו-routing
  db.js             סכמה + נתוני דמו
  auth.js           JWT והרשאות
  routes/           auth, pets, appointments, inquiries, medical, admin
public/             הממשק (index.html, styles.css, app.js)
```

## משתני סביבה

| משתנה        | ברירת מחדל | תיאור                          |
|--------------|------------|--------------------------------|
| `PORT`       | 3000       | פורט השרת                      |
| `JWT_SECRET` | נוצר אוטומטית | מפתח לחתימת טוקנים (מומלץ בפרודקשן) |
| `NODE_ENV`   | —          | `production` מפעיל עוגיות secure |
